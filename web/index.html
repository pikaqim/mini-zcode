一个类 ZCode 的 AI 编程助手。桌面版能浏览文件、写代码、跑命令；当前浏览器演示版仅提供对话能力。

1 · 配置模型填入支持 CORS 的 OpenAI 兼容 API
2 · 开始对话例如：用 JS 写一个防抖函数
3 · 获取完整版GitHub 上查看桌面版源码
